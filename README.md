# prog1.tri2.ativ4

O projeto consiste em uma plataforma web simplificada que funciona como um catálogo digital integrado ao WhatsApp, utilizando HTML, CSS, JavaScript e o banco de dados Firebase.
Para os clientes, o site oferece um sistema de cadastro e login onde ficam salvos o nome e o endereço de entrega, facilitando a navegação na vitrine de produtos.
Ao clicar no botão de compra, o sistema gera automaticamente uma mensagem formatada para o WhatsApp do lojista, contendo o item escolhido e os dados de entrega do comprador.
Para o administrador, o login libera um painel exclusivo na tela para cadastrar novos produtos (com nome, preço, categoria e foto) ou alterar itens existentes.
Dessa forma, o sistema elimina a necessidade de carrinhos de compra complexos e gateways de pagamento internos, tornando a experiência de venda muito mais rápida.
Como resultado, a solução se mantém como um software leve, seguro, de desenvolvimento ágil e que pode ser hospedado de forma 100% gratuita na internet
